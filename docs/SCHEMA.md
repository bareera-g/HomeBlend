## Firestore Collections

### `users`

**Path:** `users/{userId}`

Stores user profiles. The `userId` is a normalized version of the display name.

| Field | Type | Required | Description |
|---|---|---|---|
| `display_name` | `string` | Yes | Original display name as entered (e.g., "Abhi Patel") |
| `avatar_color` | `string` | Yes | Hex color for avatar circle (e.g., "#A67C3D") |
| `createdAt` | `timestamp` | Yes | Firestore server timestamp |

**Key generation:**
```
"Abhi Patel" → lowercase → "abhi patel" → spaces to _ → "abhi_patel" → strip non-alphanum/_ → "abhi_patel"
```

**Example document** (`users/abhi_patel`):
```json
{
  "display_name": "Abhi Patel",
  "avatar_color": "#D4A574",
  "createdAt": "2026-02-15T10:30:00Z"
}
```

---

### `rooms`

**Path:** `rooms/{roomId}`

Top-level room document. `roomId` is auto-generated by Firestore.

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | `string` | Yes | Room display name (e.g., "Abhi & Rishi's Apartment Hunt") |
| `room_code` | `string` | Yes | 6-character uppercase alphanumeric code (e.g., "K7M2PX") |
| `created_by` | `string` | Yes | `userId` of the room owner |
| `createdAt` | `timestamp` | Yes | Firestore server timestamp |

**Example document** (`rooms/abc123def456`):
```json
{
  "name": "OC Squad",
  "room_code": "K7M2PX",
  "created_by": "abhi_patel",
  "createdAt": "2026-02-15T11:00:00Z"
}
```

---

### `rooms` → `members`

**Path:** `rooms/{roomId}/members/{userId}`

Subcollection tracking room membership. One document per member.

| Field | Type | Required | Description |
|---|---|---|---|
| `joined_at` | `number` | Yes | `Date.now()` timestamp (milliseconds) |
| `role` | `string` | Yes | `"owner"` or `"member"` |
| `display_name` | `string` | Yes | User's display name (denormalized) |
| `avatar_color` | `string` | Yes | User's avatar color (denormalized) |

**Example document** (`rooms/abc123/members/abhi_patel`):
```json
{
  "joined_at": 1739617200000,
  "role": "owner",
  "display_name": "Abhi Patel",
  "avatar_color": "#D4A574"
}
```

---

### `rooms` → `properties`

**Path:** `rooms/{roomId}/properties/{propertyId}`

Subcollection of properties added to a room. `propertyId` is the numeric property ID as a string.

| Field | Type | Required | Description |
|---|---|---|---|
| `added_by` | `string` | Yes | `userId` of the member who added it |
| `added_at` | `number` | Yes | `Date.now()` timestamp (milliseconds) |

**Example document** (`rooms/abc123/properties/42`):
```json
{
  "added_by": "abhi_patel",
  "added_at": 1739617500000
}
```

---

### `rooms` → `votes`

**Path:** `rooms/{roomId}/votes/{propertyId}`

Subcollection storing all votes for a property in a room. Each document is a flat map of `userId → voteValue`.

| Field | Type | Required | Description |
|---|---|---|---|
| `{userId}` | `number` | — | `1` = like, `-1` = dislike, `2` = super like |

*The document has dynamic keys — one key per user who voted.*

**Write semantics:** Uses `setDoc(..., { merge: true })` so each user's vote is written independently without overwriting others.

**Example document** (`rooms/abc123/votes/42`):
```json
{
  "abhi_patel": 1,
  "rishi_kumar": -1,
  "colleen_smith": 1,
  "alex_jones": 1
}
```

**Vote values:**

| Value | Meaning | Context |
|---|---|---|
| `1` | Like | Web & mobile |
| `-1` | Dislike | Web & mobile |
| `2` | Super Like | Mobile only (max 3 per session) |

### `rooms` → `join_requests`

**Path:** `rooms/{roomId}/join_requests/{userId}`

Subcollection for access requests to private rooms.

| Field | Type | Required | Description |
|---|---|---|---|
| `status` | `string` | Yes | `"pending"`, `"accepted"`, or `"declined"` |
| `display_name` | `string` | No | Requester's display name |
| `created_at` | `number` | Yes | `Date.now()` timestamp |

**Example document** (`rooms/abc123/join_requests/new_user`):
```json
{
  "status": "pending",
  "display_name": "New User",
  "created_at": 1739618000000
}
```

**Status transitions:**
```
pending → accepted   (owner approves — user is added as member)
pending → declined   (owner rejects)
```

### `room_codes`

**Path:** `room_codes/{code}`

Lookup table mapping 6-character room codes to room IDs.

| Field | Type | Required | Description |
|---|---|---|---|
| `roomId` | `string` | Yes | Firestore document ID of the room |

**Example document** (`room_codes/K7M2PX`):
```json
{
  "roomId": "abc123def456"
}
```

---

### `user_rooms`

**Path:** `user_rooms/{userId}`

Tracks which rooms a user belongs to. Single document per user.

| Field | Type | Required | Description |
|---|---|---|---|
| `rooms` | `map` | Yes | `{ [roomId]: joined_at_timestamp }` |

**Example document** (`user_rooms/abhi_patel`):
```json
{
  "rooms": {
    "abc123def456": 1739617200000,
    "xyz789ghi012": 1739620000000
  }
}
```

**Lifecycle:**
- Entry added on room join/create.
- Entry removed on room leave/kick.
- Entire document deleted when last room is removed.

---

### `saved_properties`

**Path:** `saved_properties/{userId}`

User's personally saved/favorited properties (independent of rooms).

| Field | Type | Required | Description |
|---|---|---|---|
| `properties` | `map` | Yes | `{ [propertyId]: { saved_at: serverTimestamp } }` |

**Example document** (`saved_properties/abhi_patel`):
```json
{
  "properties": {
    "42": { "saved_at": "2026-02-15T12:00:00Z" },
    "87": { "saved_at": "2026-02-15T12:05:00Z" }
  }
}
```

## Server In-Memory Store

These data structures live in the Express server's memory (`server/src/store.js`). They are **not persisted** — restarting the server clears all session data.

### `sessions`

**Map:** `sessionCode → Session`

| Field | Type | Description |
|---|---|---|
| `id` | `string` | UUID |
| `code` | `string` | 5-character alphanumeric code (unambiguous charset: no 0/O/1/I) |
| `status` | `string` | `"LOBBY"` → `"SWIPING"` → `"RESULTS"` |
| `hostUserId` | `string` | UUID of the session creator |
| `constraints` | `object \| null` | Search constraints (see below) |
| `createdAt` | `string` | ISO date |
| `userCount` | `number` | Current count of joined users |
| `totalSwipes` | `number` | Total swipes across all users |

**Constraints object:**

| Field | Type | Description |
|---|---|---|
| `rentOrBuy` | `string` | `"RENT"` or `"BUY"` |
| `budgetMin` | `number` | Minimum price |
| `budgetMax` | `number` | Maximum price |
| `bedsMin` | `number` | Minimum bedrooms |
| `bathsMin` | `number` | Minimum bathrooms |
| `location` | `string` | City/area filter |
| `hardNo` | `string[]` | Features to exclude |

---

### `users` (server)

**Map:** `userId → User`

| Field | Type | Description |
|---|---|---|
| `id` | `string` | UUID |
| `sessionCode` | `string` | Session they belong to |
| `name` | `string` | Display name |
| `avatarColor` | `string` | Hex color |
| `isReady` | `boolean` | Whether user has marked themselves ready |
| `swipeCount` | `number` | Number of swipes submitted |
| `joinedAt` | `string` | ISO date |

---

### `swipes`

**Map:** `"${sessionCode}:${userId}:${listingId}" → Swipe`

| Field | Type | Description |
|---|---|---|
| `userId` | `string` | UUID of the swiper |
| `sessionCode` | `string` | Session code |
| `listingId` | `string` | Listing ID (e.g., `"lst-001"`) |
| `vote` | `string` | `"YES"`, `"NO"`, `"MAYBE"`, or `"SUPERLIKE"` |
| `createdAt` | `string` | ISO date |

---

### `sseClients`

**Map:** `sessionCode → Set<Response>`

Holds active SSE response streams for broadcasting real-time updates.

## Entity Relationships

```
users/{userId}
  │
  ├──▶ user_rooms/{userId}          (1:1 — room membership index)
  │       └─ rooms: { roomId: ts }
  │
  ├──▶ saved_properties/{userId}    (1:1 — personal favorites)
  │       └─ properties: { propId: { saved_at } }
  │
  └──▶ rooms/{roomId}               (M:N via members subcollection)
          ├─ members/{userId}        (membership + role)
          ├─ properties/{propId}     (room property list)
          ├─ votes/{propId}          (vote map per property)
          └─ join_requests/{userId}  (access requests)

room_codes/{code}
  └──▶ rooms/{roomId}               (1:1 — code lookup)
```

## Security Rules

Current rules are **open for development** — all reads and writes are allowed.

**`firestore.rules`:**
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

### Recommended Production Rules

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users can read any profile, write only their own
    match /users/{userId} {
      allow read: if true;
      allow write: if request.auth.uid == userId;
    }

    // Rooms readable by members, writable by owner
    match /rooms/{roomId} {
      allow read: if true;
      allow write: if request.auth.uid == resource.data.created_by;

      match /members/{memberId} {
        allow read: if true;
        allow write: if request.auth.uid == memberId
                     || request.auth.uid == get(/databases/$(database)/documents/rooms/$(roomId)).data.created_by;
      }

      match /votes/{propId} {
        allow read: if true;
        allow write: if exists(/databases/$(database)/documents/rooms/$(roomId)/members/$(request.auth.uid));
      }

      match /properties/{propId} {
        allow read: if true;
        allow write: if exists(/databases/$(database)/documents/rooms/$(roomId)/members/$(request.auth.uid));
      }

      match /join_requests/{reqId} {
        allow read: if true;
        allow create: if request.auth.uid == reqId;
        allow update: if request.auth.uid == get(/databases/$(database)/documents/rooms/$(roomId)).data.created_by;
      }
    }

    match /room_codes/{code} {
      allow read: if true;
      allow write: if true; // created atomically with room
    }

    match /user_rooms/{userId} {
      allow read: if true;
      allow write: if request.auth.uid == userId;
    }

    match /saved_properties/{userId} {
      allow read: if request.auth.uid == userId;
      allow write: if request.auth.uid == userId;
    }
  }
}
```

> **Note:** These production rules assume Firebase Authentication is enabled. HomeBlend currently uses name-only identity, so these would require migrating to Firebase Auth first.
